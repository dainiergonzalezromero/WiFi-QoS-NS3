Context-Aware Software-Defined Wireless Networks: An AI-Based Approach to Deal with QoS

A software-defined wireless controller enhanced with an intelligent agent that dynamically readjusts IEEE 802.11e EDCA parameters when the network topology changes, adapting QoS to the current IoT traffic conditions.

Real-Time needs

IoT Applications need Real-Time Communication and different QoS levels for each kind of traffic.

Static Parameters

WiFi/SDWN Medium-Access Parameters (EDCA) stay fixed when traffic demand or the number of nodes changes.

Our goal

Tune EDCA parameters on the fly, according to the network context, to cut delay and packet loss per traffic class.

  1. IoT Devices

    Sensors / Actuators

  2. Dynamic Traffic

    Nodes join and leave

  3. Fixed EDCA

    Same parameters always

  4. QoS Degradation

    More Delay and Loss

How CA-SDWN Works

IoT Devices send their data over WiFi. When the network changes, the Controller and the Intelligent Agent compute new parameters and send them back.

Closed-Loop Adaptation

  1. 1
    Observe

    Detect the network context: number of nodes and traffic mix.

  2. 2
    Predict

    Estimate delay, throughput and loss per class with the Random Forest.

  3. 3
    Optimize

    Search the EDCA configuration with Bayesian Optimization.

  4. 4
    Reconfigure

    Controller → Access Point → Nodes apply the new parameters.

  5. 5
    Repeat

    A node joins or leaves, or the goal changes: start again.

Event-driven: every context change triggers a new optimization cycle.

Experimental Setup

  • NS-3 Simulator, 10 random networks per size
  • 10 – 100 nodes, 20% of them mobile
  • Packets of 256 / 512 / 1024 bytes
  • Classes: High / Medium / Low / NoRT
  • 4 mechanisms compared, 95% CI

Reductions: 1024-byte packets, high and medium priority, averaged over networks of 10 to 100 nodes.

Mean of 10 networks · Shaded Area = 95% CI

  • Context-Aware

    CA-SDWN adjusts EDCA parameters according to the network context.

  • Both Metrics Improve

    Only IA SDWN lowers both metrics: standard EDCA cuts delay but raises loss; fixed tuning cuts loss but raises delay.

  • Self-Adapting

    The network responds to changes in traffic and network configuration.

  • Goal-Driven

    Performance depends on the current context and on the optimization objective.
